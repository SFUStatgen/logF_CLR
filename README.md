title: "Log-F-penalized Conditional Logistic Regression for Sparse Data"
author: Ying Yu, Jiying Wen, Jinko Graham, Brad McNeney
---

This repository contains the R code for the data analyses and
simulation study that appear in the
paper Log-F-penalized Conditional Logistic Regression for Sparse Data. The
data analyses are in the `SuppMaterials` folder and the simulation study
is in the `SimStudy` folder. See the respective README.md file in these
directories for more details.
