This directory contains the R code for the simulation study from to the
paper Log-F-penalized Conditional Logistic Regression for Sparse Data. The
main R script for the simulations is called `simstudy.R` that is written
to be called from the Slurm script `simstudy.sh` on a compute cluster. 
The cluster we used is the Alliance Canada cluster fir.alliancecan.ca.
The `simstudy.R` script is parallelized over the 480 simulation configurations
and writes results for configuration number x (for x in 1,...,480) to files 
SimRes/CLRres.x, SimRes/Firthres.x, SimRes/logFUres.x and SimRes/logFWres.x.

The simulation script calls a number of other source files that can be
categorized as data generation, analysis, and model summaries. After
the summaries are generated, there are several RMarkdown files that
prepare the figures that appear in the Simulation Study section of the
manuscript.

## Analysis

* `clogitf.R`: Code for fitting models using penalized conditional logistic regression.
The main functions are `clogitf()` for the Firth penalty and `clogitlogF()` for
log-F penalities. See also the script `choosem.R` for choosing the amount of 
shrinkage for log-F methods.
* `logFmatched.R`: the function `augment.logFmatched()` augments a dataset with
weighted pseudo matched sets. The augmented datasets can be analysed with 
the `clogit()` function from the `survival` packages.

## Model summaries

* `simsummary.R`: Takes raw batches of 10,000 simulation results for a given
simulation configuration generated by`simstudy.R` and summarizes the 
proportion of nonconvergences, estimated bias, MSE, coverage and test rejections.
These results are saved in a file `simres.txt` that is read in by other 
scripts that prepare figures for the manuscript.
* `simSummaryFuncs.R`: worker functions used by `simsummary.R`. 

## Presentation of simulation results

There are also a number of RMarkdown files that read in the simulation results
from `simres.txt` and prepare figures for the manuscript.

* `convergence.Rmd`: Prepare the figures in Section 4.1 to show the rates of non-convergence for the 
different methods. Figures are nonconv.eps and nonconv.pdf.
* `estimation.Rmd`: Prepare the figures in Section 4.2 to show the bias and MSE of 
the point estimators and coverage of the interval estimators. Figures are
bias.eps, bias.pdf, MSE.eps, MSE.pdf, cover.eps and cover.pdf.
* `inference.Rmd`: Prepare the figures in Section 4.3 to show estimated type 1 error
rates and power of the hypothesis tests. Figures are t1e.eps, t1e.pdf, power.eps
and power.pdf.
