The Supplementary Materials of the 
manuscript. This includes the details of the DES and type 2 diabetes
trio data analyses, and a table of the complete simulation results.
The file `suppMat.Rmd` combines these into a single Supplementary 
Materials PDF called `suppMat.pdf`.

Files list:

* `DES-analysis.Rmd`: Analysis of the DES data. Reads in the data from
`DES.csv`. Generates the profile likelihood plots 
in `DESprofile.eps` and `DESprofile.pdf`.
* `trio-analysis.Rmd`: Analysis of the type 2 diabetes trio data.
